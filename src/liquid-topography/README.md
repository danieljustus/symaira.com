`symaira-appkit` at commit `44782b9` (Liquid Topography, Google Sans Flex).
Change the source there first, verify its tests, then copy the artifacts here.
The web build must stay standalone and never depend on a sibling checkout.

Rules carried over from `DESIGN.md`:

- Canvas `#1C1C1B`, surface `#141413`, line `#30302E`, champagne `#E0D2BA` as the
  only accent. The site is dark-only: `index.html` pins `data-theme="dark"`.
- Google Sans Flex is served from this origin (OFL 1.1 and trademark notice sit
  next to the font). No font CDN, no subsetting or renaming, `opsz` fixed at 18
  by `tokens.css`, weights 500/600/700 (650 for titles).
- Web uses opaque surfaces only; no `backdrop-filter` glass, no glows, no
  gradients on surfaces or text.
- Text and controls are topography protection zones at their own bounds
  (`TopoBackground.tsx`); `prefers-reduced-motion` is handled by the engine.

`symaira-topo.d.ts` describes the imported component API; it is not a second
implementation. The lifecycle/masking test lives with the source in AppKit
(`web/symaira-topo.test.mjs`).
