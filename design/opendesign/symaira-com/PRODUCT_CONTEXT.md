# Product Context — symaira.com

**Repository:** `/Users/daniel/Dev/Symaira Dev/symaira.com`
**Product role:** Public Vite/React website for the Symaira ecosystem.

## Product focus

The website explains the surviving Symaira products, their open-source/self-hosted positioning, capabilities, installation paths, supported platforms, and boundaries. It supports German and English content and uses the existing hash-based routing architecture.

## Design priorities

- Use the Symaira Web Expression: warm-black technical canvas, Champagne/Sand accents, Roboto Flex Variable, restrained blueprint grid, readable sections, and purposeful atmospheric glow.
- Give each surviving product a distinct page and clear product promise without merging the products into one dashboard.
- Keep install commands, platforms, license, open-source status, and product boundaries visible.
- Preserve EN/DE content, keyboard access, responsive cards, visible focus, reduced motion, and accessible contrast.
- Verify product availability and release claims against `src/config/products.tsx`, `src/App.tsx`, and current repository state before adding copy.

## Content boundaries

The current workspace inventory is authoritative. Absorbed tools are described under their surviving products; deleted products are not reintroduced merely because older documents mention them. Do not promise hosted Pro availability without a released and documented contract.
